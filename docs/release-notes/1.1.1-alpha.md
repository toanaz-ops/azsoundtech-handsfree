# Hands-free 1.1.1 alpha — bản gộp: phát hiện hú theo làn + chuỗi preset

> **Thay thế 1.1.0.** Bản 1.1.0 build từ nhánh stereo trên nền 1.0.4 nên
> thiếu LOAD/SAVE và preset mặc định của 1.0.5. Bản 1.1.1 gộp cả hai.
> Cài 1.1.1, bỏ 1.1.0.

## Có gì trong 1.1.1

- **Mọi thứ của 1.1.0** (phát hiện theo làn, INDEP mặc định, nút LINK/INDEP,
  cột LANE, bộ chọn L/R trên analyser, stem đứt nét cho notch cánh phải) —
  đọc [`1.1.0-alpha.md`](1.1.0-alpha.md) cho phần "Mức thay đổi level dự
  kiến"; con số không đổi.
- **Mọi thứ của 1.0.5**: installer chép sẵn preset `Speech` và `Music`, lần
  đầu mở app tự nạp vào `%APPDATA%\AZSoundtech\HandsFree\presets\`, hai nút
  **LOAD… / SAVE…** dưới mục INTERFACE.
- **SAVE hiểu làn**: file preset nay ghi mỗi notch kèm `lane` (0 = L, 1 = R)
  và mỗi slot kèm `linked`, nên một slot INDEP có notch L và R khác nhau
  lưu rồi nạp lại đúng từng cánh. File cũ (không có `lane`) vẫn nạp được với
  nghĩa cũ: notch áp cho cả hai làn.

## Điều cần biết

- **File do 1.1.x lưu không mở được bằng 1.0.5** (1.0.5 từ chối hai notch
  cùng index dù khác làn). Ngược lại thì được.
- SAVE chỉ ghi các slot **đang bật**. Slot đã cấu hình routing nhưng tắt sẽ
  không nằm trong file.
- Chưa ai nghe bản này trên rig thật. Mức thay đổi level là dự đoán từ
  code theo đúng quy ước "nghe ở alpha".

## Kịch bản test thêm so với 1.1.0 (5 phút)

1. Slot 01 stereo, INDEP. Gây hú cánh trái → dòng L; gây hú cánh phải ở tần
   số khác → dòng R.
2. Bấm **SAVE…** ra `test-lane.json`. Mở file bằng Notepad: mỗi notch có
   `"lane": 0` hoặc `"lane": 1`.
3. CLEAR ALL → **LOAD…** file vừa lưu → bảng ACTIVE NOTCHES hiện lại đúng
   hai dòng L và R với tần số cũ; nút LINK/INDEP của slot giữ nguyên trạng
   thái đã lưu.
4. Bật LINK cho slot 02 → SAVE → LOAD → slot 02 vẫn LINK.

Thấy ring dai một bên trong khi bên kia đã cắt → bật LINK cho slot đó và
báo lại.
